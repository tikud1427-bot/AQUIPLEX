## What changed
All 28 response points in `aqua/src/routes/memory.js` now go through `ok()` / `fail()`. The only wire-visible change is a new `code` field on failures (`bad_request` / `not_found`). Statuses, `error` text, `ownerId` and the engine's `ok` field are unchanged.

The edit endpoints share one `respondEdit()` that takes the failure code explicitly so the difference is visible in the code. Changing either is a client-visible decision, not a migration.
