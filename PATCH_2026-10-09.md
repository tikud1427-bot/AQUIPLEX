### Result — 2 of 6 personas (20 questions × 4 conditions, 0 judge errors)

Personas 3–6: **BLOCKED** — every registry-listed extraction model (Groq
gpt-oss-120b, Gemini 2.5-flash, Gemini 3.5-flash) hit its free-tier DAILY quota,
so their World Models cannot be built through the production E6 transport today.
Substituting an unlisted extractor would stop testing the production path, so I
did not. Extraction here: Gemini 3.5-flash via `AQUA_E6_PROVIDER=gemini` (Groq
was exhausted). Answerer: gemini-3.5-flash (persona 1) / gemini-flash-lite-latest
(persona 2) — identical across conditions within each question. Judge:
gemini-3-flash-preview, blind to condition. Record:
`aqua/eval/out/world-model-lift-live.p1p2.json`.

| metric | A stateless | B memory (BM25 k=8) | B′ full history | **C World Model** |
|---|---:|---:|---:|---:|
| strict correctness | 15% | 60% | 100% | **60%** |
| required-fact recall | 0% | 58.8% | 100% | **76.5%** |
| personalization | 0% | 58.8% | 100% | **76.5%** |
| temporal accuracy (stale facts) | 100%* | 80% | 100% | **80%** |
| unknown honesty | 100% | 100% | 100% | **100%** |
| fabrication rate | 0% | 5% | 0% | **20%** |
| asked for known info (re-explanation proxy) | 75% | 35% | 0% | **5%** |

* stateless knows nothing, so it cannot assert a stale fact.

Paired, strict correctness (sign test): C vs B **4 / 4 / 12, p = 1.0** (no
difference); C vs A 9 / 0 / 11, p = 0.004; C vs B′ **0 / 8 / 12, p = 0.008**
(C worse). C context: 8 items/question, 100% provenance coverage, 0
`undefined`/`[object Object]` lines.

**Answer to "does understanding beat memory?" — not yet.** C recalls more of
what is needed (76.5% vs 58.8%) and almost never asks the user to repeat
themselves (5% vs 35%), but it asserts stale or wrong facts four times as often
(20% vs 5%), and the two cancel. With histories this short, putting the whole
history in context (B′) wins outright; the World Model's advantage, if it has
one, has to show up where the history no longer fits.

**Root causes (measured on these runs, general, not fixed by tuning):**
1. *A changed fact does not retire the old one.* "The GPU cluster is fixed now" is
   stored as a separate `has_status` claim, so `blocked_by: GPU outage` stays
   active; "Kavya no longer works on payments" negates `member_of payments` while
   `owns payment integration` stays active. S8 detects only same-predicate,
   same-object polarity flips (plus `works_at` when `AQUA_E6_SINGLE_VALUED=on`),
   and the contradiction policy disputes both sides rather than retiring either.
2. *Extraction recall gaps:* "My thesis is on protein folding with graph neural
   networks" → no claim; "it's Dr. Sofia Marquez" → only the negation of Liam
   Chen stored.
3. *Possessive-role subjects are refused by design* ("our office moved to
   Bangalore"), so the move never lands.
4. Earlier in the pass (run 1, before fixes 3–5) C also lost facts it HELD, to
   `[object Object]`, duplicate lines and missing neighbour facts — seen directly
   in its contexts. Persona 1 scored 3/10 for C then and 5/10 now, but run 1 used
   Gemini 2.5-flash for extraction and answers and this run 3.5-flash, so that
   change is confounded and is NOT claimed as the fixes' effect.
