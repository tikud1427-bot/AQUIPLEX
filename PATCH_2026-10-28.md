## 1. Root causes

### Task 1 — sensitive facts on every reply

**Extraction.** The `custom_fallback` extractor (`memory/candidateExtractor.js`) stores:
- "I'm very bored" → `custom_very_bored`. Its `TRANSIENT_STATE` guard matches only a bare leading "bored", not "very bored".
- "my right eye is moving automatically" → `custom_right_eye`, through the unguarded `my X is Y` pattern.

**Selection.** On a generic message ("help me write a cold email") the
retriever's only gate is `score ≥ 50`. Base score is importance × 15 +
confidence × 20, which is 74 for a fallback fact. So every stored fact passes,
up to 15 per turn. `touchRetrieved` then raises `retrievalCount`, which feeds
importance. That is the Memory page's "Used 233×".

**Other lanes that answer.** The same sentence also sits in:
- the conversation evidence lane (PIC), which quotes the raw sentence;
- the Mind (beliefs, graph, episodes);
- with a database, the canonical claims (E6).

### Task 2 — UI leaks

| Leak | Source |
|---|---|
| a "event" | Mind timeline events are `{kind, subject}`; `whatChanged` read `e.type` / `e.text`, which don't exist, and fell back to the literal `'event'`. |
| b `custom_` headings | `humanizeKey(fact.key)` used as the heading; the change feed printed `key = "value"`. |
| c run-on goals | A merged collection is an array; React renders `{array}` with no separator. The feed printed `goal: was "…" (collection_merge)`. |
| d `loveit` | `validateLanguage` accepted any string longer than one character. "I hate mondays" → `least_favorite_language=mondays`; "I hate it, I love it" filled both slots with "it". |
| e/f `Domain:alpha` | `fileBridge.toSignals` made a `domain:` belief from every enrichment topic. For a maths PDF those topics are LaTeX commands. |
| g `simple_qa` | Classifier task types are pushed into working-memory focus. From there they become episode titles ("Working on simple qa + memory recall") and predictions. |
| h Profession: billionaire | The `i_am_a` pattern took "I am a billionaire". Schema matches count as explicit declarations, so the belief starts at 0.9. The evidence line was a hard-coded string per key. |
| i 100% badge | `ConfidenceBadge` without a label, beside a position slider. |
| j filenames | Uploaded files are `artifact` graph nodes labelled with raw filenames. |
